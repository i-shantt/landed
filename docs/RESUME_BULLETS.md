# Résumé bullets

Each bullet is traceable to a file or a generated number. Numbers are as of 2026-11-06; re-check `README.md` (measured and model blocks) before reuse.

## Software engineering

- Built **Landed**, a payment-control platform for accounts payable (Next.js 16, React 19, Convex, TypeScript) that refuses any payment to a bank account not verified for that vendor inside the database transaction; 40/40 scripted fraud and legitimate scenarios pass against a live deployment with zero false releases, including with the AI extractor disabled. (`web/convex/payments.ts`, `guard.ts`, `eval/`)
- Designed a verification engine around a probe deposit read back by the vendor's contact of record over voice (Vapi, Cartesia) or a vendor portal, with a 16-check release gate, SLA timers and landing confirmation; a static test proves the AI paths cannot import or schedule any release function. (`web/convex/cases.ts`, `channels/`, `tests/security.test.ts`)
- Shipped email + password authentication (Convex Auth) with invite-by-email, server-resolved operator roles, maker-checker approvals and segregation of duties; removed every client-supplied identity argument from 19 functions, moved all 68 reads behind the session with internal twins for the REST and eval layers, and enforced both with static tests. (`web/convex/controls/actor.ts`, `auth.ts`)
- Built sanctions screening on the live OFAC SDN list: a Node-runtime loader that fetches the Treasury's fixed exports, versions the 19k-entry list by SHA-256, re-screens the vendor master on every change and fails the payment boundary closed for any vendor not yet screened against the list in force; Jaro-Winkler and token-sort matching with approver dispositions. (`web/convex/screening/`)
- Exposed a REST API v1 (scoped hashed keys, idempotency, cursor pagination, OpenAPI 3.1) and HMAC-signed webhooks with exponential retries and an SSRF guard; generated Nacha ACH and ISO 20022 `pain.001` files from guard-approved lines only. (`web/convex/apiRoutes.ts`, `webhooks/`, `exports/`)
- Established a quality gate (343 vitest invariant and property tests in an in-memory Convex, a 40-run scenario suite, drift checks that regenerate the README's numbers from artifacts, Playwright smoke) and CI on GitHub Actions; documented 21 controls against SOC 2, NIST CSF 2.0 and COSO with the test that proves each. (`scripts/verify.sh`, `.github/workflows/`, `/compliance`)
- Wrote property-based tests (fast-check) that prove the release gate refuses every combination of binding perturbations and never leaks an amount-derived refusal for an unaccepted statement, that Nacha build→parse and ISO 20022 sums, escaping and masking hold for any generated batch, and that the monitoring signals, trust score, drift statistics (PSI, Spearman) and both model scorers keep their bounds, partitions and order invariances for any generated history or feature vector; wrote a threat model over eight trust boundaries with the test behind each control. (`web/tests/properties.test.ts`, `docs/THREAT_MODEL.md`)
- Benchmarked the REST API per route (p50 ≈ 130 ms end to end from a laptop) and found with a 150-request burst that the per-key token bucket surfaced database write conflicts as HTTP 500; changed the API to answer 429 with a retry hint and added dependency audits and CodeQL to CI. (`web/scripts/bench-api.mjs`, `docs/BENCHMARKS.md`, `.github/workflows/`)
- Hardened after an external-style review: closed a probe-amount oracle, bound voice webhooks to calls the system placed, encrypted account numbers at rest (HMAC + AES-256-GCM) and kept them out of the browser; append-only audit log with a hash chain. (`SECURITY.md`, `CHANGELOG.md`)

## Data / ML

- Trained and shipped a learned risk layer for accounts payable: 200 gradient-boosted trees over 20 behavioural features (velocity, amount vs. beneficiary and payer medians, beneficiary age, structuring proximity) on 4.6 M public PaySim and Sparkov rows with leakage-free time splits; held-out ROC-AUC 0.980 / PR-AUC 0.558 combined, 4× the PR-AUC of the logistic-regression baseline (0.877 / 0.134) that ships alongside as the glass-box comparison. (`ml/train.py`, `ml/artifacts/metrics.json`)
- Exported the scikit-learn trees as 155 KB of node arrays and wrote a 40-line TypeScript walker with Saabas path attributions (per-feature contributions that sum exactly to the logit), so the boosted model runs inside the database read path with full-precision thresholds; 50 fixtures match Python to 1e-9. (`ml/trees.py`, `web/convex/risk/model/trees.ts`)
- Built a TF-IDF (3,000 uni/bigrams) + logistic-regression email model on 27.8 k phishing and advance-fee emails (test ROC-AUC 0.995) with an ASCII tokenizer that TypeScript reproduces exactly; 150 parity fixtures match the Python scores to 1e-6 so the exported JSON weights are the cross-language contract. (`ml/text.py`, `web/convex/risk/model/`, `web/tests/modelParity.test.ts`)
- Chose the operating threshold by minimising expected cost on validation (C_FN/C_FP = 20) and reported the implied review rate, precision@k, recall at fixed false-positive rates, Brier score and reliability bins; evaluated separately on a synthetic AP scenario set and stated plainly which families the model misses and which deterministic rules own them. (`ml/evaluate.py`, `ml/artifacts/MODEL_CARD.md`)
- Implemented transaction monitoring computed on read from each vendor's own history (robust z-score with MAD, velocity vs. weekly median, 72-hour structuring clusters under the approval threshold, dormant-vendor spikes) plus a 0–100 beneficiary trust score and a 7/30-day risk trend API. (`web/convex/monitoring/`)
- Added production model monitoring computed on read: population stability index of recent vs. earlier scores, per-feature drift against the training reference exported with the model (validation-window deciles), and champion-vs-baseline agreement (Spearman, flag disagreement), served on the Monitoring page and `GET /api/v1/model/health`, with thresholds that stay silent below a minimum sample. (`web/convex/monitoring/drift.ts`, `ml/export.py`)
- Closed the feedback loop: operator dispositions (landed, attested, unconfirmed, fraud reported, recovery) become labels joined with the feature vector scored at send time, exported through `GET /api/v1/model/labels` as JSONL; a Python evaluator rescores the export with the shipped trees (parity asserted) and reports ROC/PR-AUC and the confusion matrix for trees, baseline and rules, so the in-domain evaluation the public-data model card cannot give accumulates in production. (`web/convex/monitoring/labels.ts`, `ml/feedback.py`)
- Made the pipeline reproducible: declarative data registry with resumable sha-verified fetch from Hugging Face, committed manifest and model card, `make -C ml all` reproduces `metrics.json` byte-for-byte, and a GitHub Actions workflow re-runs it on a clean runner and fails on drift. (`ml/data/`, `ml/Makefile`, `.github/workflows/ml.yml`)

## One-line project summary

Landed — payment controls for AP that make unverified bank changes unpayable at the database boundary; verification by probe deposit and contact of record, deterministic + learned risk (boosted trees scored in TypeScript), maker-checker controls, REST API, Nacha/ISO 20022 files; 343 tests, 40/40 scenarios, live on Vercel + Convex.
